# Clip Syndicate - Dark Psychology Studio

Turn a mind game into a slideshow and Make $$.

## Features
- **Mind Game Slideshow Creator**: Hook, Chat beats, Reaction slides, CTA.
- **Viral App Screenshot Templates**:
  - `rizz:` RIZZ App Screenshot
  - `plug:` Plug AI Template (Asymmetric bubble, red chevron header, outline badge)
  - `wrizz:` WRizz Template (Dynamic brackets, neon divider, purple gradient pill)
- **High-Res Export**: 1080×1920 PNGs and ZIP export (`C-S-YYYY-MM-DD.zip`).
- **DM Screenshot Studio (`/promo`)**:
  - **Instagram DM Studio (`IG-Dm`)**: Full reverse-engineered Slideshows.gg Instagram DM story slides generator with purple gradients, smart quotes, story reply card, dual-look toggle (`Full screen` 1318×2346 & `Close-up` 828w), and batch ZIP exporter.
  - **iPhone DM Mockup**: Configurable iOS text message generator with Tapbacks, sponsor prediction cards, and light/dark theme.
  - **Multi-Slide Carousel**: Script-driven multi-slide cliffhanger sequences.
- **Brand Protection**: Team authentication gate.

## Local Development
```bash
npm start
```
Runs at `http://localhost:3000`.

## Vercel Deployment
Deploy with 1-click via Vercel CLI or by connecting your GitHub repository to Vercel:
```bash
vercel
```

### Environment Variables (Optional)
- `PASSWORD`: Custom team password (default: `Clip_Syndicate@03`)
- `UPSTREAM_SESSION`: Upstream generation session token for AI completions
